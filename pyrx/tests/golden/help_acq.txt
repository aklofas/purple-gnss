usage: pyrx-acq [-h] --fs FS [--f-if F_IF] [--iq] [--signal {L1CA,L5,E5A}]
                [--prn PRN] [--t-start T_START] [--duration DURATION]
                [--plot PLOT]
                file

Acquire the PRNs of a signal in a recording and print one line per PRN.

positional arguments:
  file

options:
  -h, --help            show this help message and exit
  --fs FS               sample rate (Hz)
  --f-if F_IF           intermediate frequency (Hz)
  --iq                  file holds interleaved I/Q bytes
  --signal {L1CA,L5,E5A}
                        signal to search: GPS L1 C/A, or the pilot of GPS L5
                        or Galileo E5a (default L1CA)
  --prn PRN             PRNs, e.g. 1-32 or 1,5,7 (default: all of the
                        signal's)
  --t-start T_START     start offset in the file (s)
  --duration DURATION   length to integrate (s), 0 for the whole file (default
                        0.02)
  --plot PLOT           directory for cn0.png and acq_prnNN.png
