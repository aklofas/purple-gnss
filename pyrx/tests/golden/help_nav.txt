usage: pyrx-nav [-h] --fs FS [--f-if F_IF] [--iq] [--prn PRN]
                [--t-start T_START] [--duration DURATION] [--json JSON]
                file

Acquire, track and decode the navigation message of GPS L1 C/A PRNs in a
recording.

positional arguments:
  file

options:
  -h, --help           show this help message and exit
  --fs FS              sample rate (Hz)
  --f-if F_IF          intermediate frequency (Hz)
  --iq                 file holds interleaved I/Q bytes
  --prn PRN            PRNs, e.g. 1-32 or 1,5,7
  --t-start T_START    start offset in the file (s)
  --duration DURATION  length to decode (s), 0 = all
  --json JSON          write decoded ephemerides and ionosphere here
