# Notebooks

Three Jupyter notebooks that walk the receiver from recorded samples to an RTK fix, with
a figure at every step. They are committed with their outputs, so GitHub renders them
without running anything.

| Notebook                                             | What it shows                                                                                                   |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| [`01-signal-chain.ipynb`](01-signal-chain.ipynb)     | the raw samples, acquisition, the tracking loops settling, the navigation message, observables, a RINEX file    |
| [`02-standalone-pvt.ipynb`](02-standalone-pvt.ipynb) | satellite orbits against the precise ephemeris, the atmosphere models, a single-point fix epoch by epoch         |
| [`03-rtk.ipynb`](03-rtk.ipynb)                       | single and double differences, the float filter, LAMBDA and the ratio test, a centimetre baseline against truth |

Each notebook ends with a comparison against the references the test suite uses (Pocket
SDR's trackers, RTKLIB's `rnx2rtkp`), after the walk through our own processing.

## Running them

Install the package with the notebook extras and start Jupyter from this directory:

```sh
pip install -e 'pyrx[dev,notebooks]'
cd pyrx/notebooks
jupyter lab
```

With the environment variable `PYRX_CAPTURES` pointing at the recordings directory
described in [`../README.md`](../README.md), the notebooks run on the 2021-12-26 recording
and the IGS station files; the committed outputs come from that path. Without it they
run on synthetic signals and observations generated by `pyrx.synth`, so every figure is
produced from a fresh clone (the synthetic signal-chain notebook synthesises and tracks
22 s of four satellites, which takes under a minute). The RTKLIB comparisons need
`rnx2rtkp` on the path and print a note when it is absent.

To re-execute a notebook in place from the command line, with the kernel running in the
interpreter the package is installed in:

```sh
python -m nbconvert --to notebook --execute --inplace 01-signal-chain.ipynb
```
